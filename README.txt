HANNAH JENNIFER — PORTFOLIO WEBSITE

FILES
- index.html: responsive, single-page portfolio website
- Hannah-Jennifer-CV.pdf: CV linked from the homepage

PREVIEW LOCALLY
1. Keep index.html and Hannah-Jennifer-CV.pdf in the same folder.
2. Double-click index.html to open it in a modern browser.

FREE HOSTING WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named: hannah-jennifer-portfolio
2. Upload index.html, Hannah-Jennifer-CV.pdf and this README file to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
5. Wait for GitHub Pages to publish. Your site will be available at a URL similar to:
   https://YOUR-GITHUB-USERNAME.github.io/hannah-jennifer-portfolio/
   Replace YOUR-GITHUB-USERNAME with your actual GitHub username.

OPTIONAL CUSTOM DOMAIN
1. Buy a domain from a registrar (for example, hannahjennifer.com, if available).
2. In repository Settings > Pages > Custom domain, enter the domain and Save.
3. Add the DNS records shown by GitHub at your domain registrar. DNS values vary by domain and setup; follow GitHub's current instructions.
4. Once DNS is verified, enable Enforce HTTPS in GitHub Pages settings.
